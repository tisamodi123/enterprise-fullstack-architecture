# TaskMaster TS — Next.js & TypeScript Task Manager

A modern, type-safe task dashboard built with Next.js App Router, Tailwind CSS, and strict TypeScript types.

---

## ✨ Features

- **Strict TypeScript Architecture**: Leverages TypeScript union types (`TaskStatus = 'Todo' | 'In-Progress' | 'Completed'`) and typed task interfaces.
- **Custom `useLocalStorage` Hook**: Synchronizes local state seamlessly with browser `localStorage` with JSON serialization safety.
- **Component Modularity**: Separation of concerns across `TaskCard`, `TaskForm`, and filter mechanisms.
- **Responsive Layout**: Designed for mobile and desktop viewports.

---

## 🚀 Getting Started

```bash
cd typescript_miniProject/my-ts-app
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the application.
